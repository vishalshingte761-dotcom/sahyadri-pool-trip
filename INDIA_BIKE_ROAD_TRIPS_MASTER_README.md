# INDIA_BIKE_ROAD_TRIPS_MASTER.csv

15 long-distance / classic motorcycle road-trip candidates for the Sahyadri Pool & Trip **Biker Routes** section.

- Distances are route-planning estimates, not live navigation distances.
- Route availability, weather, road conditions, permits and access can change.
- All records are intentionally marked `AI_CURATED_NEEDS_VERIFICATION` / `DRAFT_FOR_REVIEW`.
- The frontend currently uses the same curated list for the Biker Routes UI; the CSV is provided for later backend import.
